# 리센느 라이브 검색

**https://scentiment-rs.github.io/rescene-live-search/**

"그 얘기 어느 라이브였지?" 리센느(RESCENE) 유튜브 라이브에서 기억나는 장면을 찾아주는 팬 사이트입니다.
검색 결과의 ▶ 를 누르면 그 장면부터 바로 재생돼요.

## 이렇게 검색해 보세요

- 기억나는 말: `검은 건반`, `떡볶이`
- 장면 묘사: `리브가 가리지 말라고 한 장면`, `원이 핫도그 시무룩`
- 멤버 별명도 인정해요: `까엉이` → 제나, `파이리` → 원이
- 띄어쓰기는 상관없어요
- 검색 결과 주소를 그대로 공유할 수 있어요

## 무엇을 검색하나요

| 데이터 | 설명 |
|---|---|
| 💬 팬들이 댓글로 남긴 장면 | 유튜브 댓글에 팬들이 남긴 타임스탬프와 설명 (작성자 정보는 저장하지 않아요) |
| 🎙 라이브 대화 | 라이브 음성을 자동으로 받아쓴 내용과 유튜브 자동 자막 |

리센느 공식 유튜브 채널의 라이브를 대상으로 하며, 새 라이브와 댓글은 매주 반영됩니다.

## 알아두세요

- 라이브 대화는 **자동 받아쓰기**라 틀린 글자가 있을 수 있어요. 찾는 장면이 안 나오면 다른 표현으로 검색해 보세요.
- 서비스 개선을 위해 **검색어만 익명으로** 집계해요. 쿠키나 개인 정보는 수집하지 않아요.
- 영상과 그 내용의 저작권은 리센느와 소속사 등 각 권리자에게 있습니다. 권리자의 요청이 있으면 관련 내용을 수정하거나 삭제합니다.
